# ПОРЦИЯ — сервис заказов для общепита

Киоск самообслуживания, экран кухни, табло выдачи и панель управления в одном self-hosted сервисе:
гость заказывает и платит на киоске → заказ мгновенно появляется на кухне → готовый номер
всплывает на табло выдачи → всё видно в панели управления.

**Стек:** Node.js 18+ без единой внешней зависимости (HTTP, файловое хранилище, SSE для live-обновлений).
Ни сборки, ни `npm install` не нужно.

## Быстрый старт

```bash
git clone <адрес-репозитория> porcia
cd porcia
node server.js            # http://localhost:3000
PORT=8080 node server.js  # другой порт
```

Демо-заказы в разных статусах (чтобы кухня и табло сразу выглядели живыми):

```bash
node tools/seed-demo.js
```

## Экраны

| URL        | Что это | Для кого |
|------------|---------|----------|
| `/`        | Витрина сервиса, карта всех экранов | демонстрация |
| `/demo`    | Киоск + кухня + табло в одном окне | показ за 1 минуту |
| `/kiosk`   | Киоск: меню, модификаторы, корзина, оплата, номер заказа | гость |
| `/kitchen` | Экран кухни (KDS): тикеты, таймеры, звук, статусы | повар |
| `/board`   | Табло выдачи: номера готовых заказов, очередь, озвучка | зал |
| `/admin`   | Панель: выручка, заказы, меню, комбо, модификаторы, настройки | управляющий |

## Возможности

**Киоск**
- Категории, блюда с фото, описанием, КБЖУ и бейджами («Хит», «Новинка»)
- Модификаторы двух типов: одиночный выбор (размер пиццы, объём) и мультивыбор (бекон, сиропы)
- Корзина с изменением количества, баннер комбо (состав и цена задаются в панели)
- Оплата: карта на киоске (демо-эквайринг с анимацией терминала) или на кассе — режим задаётся в настройках
- Экран «Приложите карту» → подтверждение → номер заказа и чек
- Экран привлечения («Коснитесь экрана») для простоя
- Стоп-лист: выключили блюдо в панели — оно исчезло из киоска и из корзины гостя

**Кухня (KDS)**
- Три колонки: поступили → готовятся → готовы к выдаче
- Таймер по каждому заказу, подсветка «горит» после 9 минут
- Звук нового заказа и звук готовности (WebAudio, без файлов)
- Один клик меняет статус, отмена заказа; интерфейс не мигает и не теряет клики

**Табло выдачи**
- Готовые номера крупным планом, анимация появления, очередь «сейчас готовятся»
- Голосовое объявление номера (SpeechSynthesis)

**Панель управления**
- Выручка за день, число заказов, средний чек, позиции, заказы в работе, график по часам, топ блюд
- Заказы: фильтры «в работе / завершённые / все», ручная оплата, смена статусов
- **Блюда:** карточки с фото, название, цена, категория, описание, КБЖУ, бейдж, «в продаже / стоп-лист»,
  «Популярное», модификаторы, удаление; поиск и фильтр по категории
- **Создание блюда:** мастер с фото, всеми полями и модификаторами за один шаг
- **Фото:** библиотека готовых, загрузка файла (перетаскиванием, со сжатием в браузере до 900 px) или ссылка
- **Категории:** создание с иконкой и позицией, переименование, порядок стрелками, удаление
- **Комбо:** название, плашка, описание, цена, состав с количеством, фото, показ на киоске,
  автоматический расчёт выгоды гостя
- **Модификаторы:** группы (один вариант / несколько, обязательность), варианты с доплатами,
  удаление с отвязкой от блюд
- Настройки: название, адрес, тексты киоска, среднее время приготовления, способы оплаты, сброс демо-данных

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET  | `/api/state` | меню, категории, модификаторы, комбо, заказы, настройки |
| GET  | `/api/stats` | метрики за сегодня |
| GET  | `/api/events` | SSE-поток: `order`, `menu`, `stats`, `reset` |
| POST | `/api/orders` | создать заказ (цены пересчитываются на сервере) |
| POST | `/api/orders/:id/status` | `cooking` · `ready` · `done` · `cancelled` |
| POST | `/api/orders/:id/pay` | отметить оплату (касса) |
| POST/PATCH/DELETE | `/api/products`, `/api/products/:id` | управление меню и стоп-листом |
| POST | `/api/products/reorder` | порядок блюд в меню |
| POST/PATCH/DELETE | `/api/categories`, `/api/categories/:id` | категории |
| POST | `/api/categories/reorder` | порядок категорий в киоске |
| POST/PATCH/DELETE | `/api/combos`, `/api/combos/:id` | комбо: состав, цена, показ на киоске |
| POST/PATCH/DELETE | `/api/modgroups`, `/api/modgroups/:id` | группы модификаторов |
| POST/PATCH/DELETE | `/api/modgroups/:id/options/:oid` | варианты и доплаты внутри группы |
| GET  | `/api/images` | библиотека фото (готовые + загруженные) |
| POST | `/api/upload` | загрузка фото (`{ "data": "data:image/jpeg;base64,…" }`) |
| PATCH | `/api/settings` | настройки заведения |
| POST | `/api/reset` | сбросить демо-данные |

Пример создания заказа:

```bash
curl -X POST localhost:3000/api/orders -H 'Content-Type: application/json' -d '{
  "items": [
    {"productId": "doublecheese", "qty": 1, "mods": [{"groupId":"burger-add","optionId":"bacon","name":"Бекон","price":79}]},
    {"productId": "cappuccino", "qty": 2, "mods": [{"groupId":"coffee-size","optionId":"c400","name":"400 мл","price":50}]}
  ],
  "payMethod": "card"
}'
```

## Структура

```
porcia/
├── server.js            # HTTP-сервер, API, SSE, статика
├── lib/seed.js          # стартовое меню, категории, модификаторы, комбо
├── tools/seed-demo.js   # наполнение демо-заказами
├── data/                # рантайм (в git не попадает)
│   ├── db.json          #   меню и заказы
│   └── uploads/         #   загруженные фото
└── public/
    ├── index.html       # витрина сервиса
    ├── demo.html        # все экраны в одном окне
    ├── kiosk.html       # киоск
    ├── kitchen.html     # кухня
    ├── board.html       # табло выдачи
    ├── admin.html       # панель управления
    └── assets/          # стили, API-клиент, фото блюд
```

## Заметки по эксплуатации

- Данные лежат в `data/db.json`; каталог `data/` исключён из git — для продакшена замените
  файловое хранилище на БД (точки изменения: `load()`, `save()`, `publicState()` в `server.js`).
- `*.html`, `*.js`, `*.css` отдаются с `no-cache`, картинки — с суточным кешем.
- Демо-оплата «проходит» за ~0.9 с на сервере (`POST /api/orders`), реальный эквайринг
  подключается в этом же месте.
